## 📖 About The Project

**Pranzo** is a web-based platform designed for an Italian restaurant. Built in Visual Studio Code, this project integrates a responsive frontend with a PHP-driven backend and a MySQL database. It allows customers to create accounts, browse dynamic content, and seamlessly book tables for their dining experience.

### ✨ Key Features
*   **User Authentication:** Secure registration and login system for customers.
*   **Dynamic Menu:** Browse the restaurant's menu through a dropdown list populated directly from the backend database.
*   **Table Reservations:** Book a table using an interactive form; all reservations are securely stored in the database.
*   **About Us Section:** Discover the story and meet the team running the restaurant.

## ⚙️ Installation & Setup

To run this project locally, you must use a local server environment like **XAMPP**. Follow these steps carefully:

**1. Start XAMPP:**
Open the XAMPP Control Panel and click **Start** for both the **Apache** and **MySQL** modules.

**2. Database Configuration:**
*   Open your web browser and navigate to `http://localhost/phpmyadmin`.
*   Create a new database and name it **exactly** `pranzo` (the application will not work with a different name).
*   Select the newly created `pranzo` database.
*   Go to the **Import** tab and upload the `pranzo (1).sql` file located in the main project folder. Click **Go** to execute and build the tables.

**3. Project Placement:**
Move the entire project folder (named `PRANZO-MAIN`) into your XAMPP `htdocs` directory.
*   *Windows default path:* `C:\xampp\htdocs\`
*   *macOS default path:* `/Applications/XAMPP/xamppfiles/htdocs/`

**4. Run the Application:**
Open your web browser and paste the following URL to access the main page:
```text
http://localhost/Pranzo-main/HTML&PHP/Pranzo.html
```
